# Freeform calendar workout contract

The lead verified title-only Run and Day off save/reopen behavior in the reference. Empty planned duration and distance remain empty; they do not imply a zero-length executable workout.

`WorkoutModel.unstructured?: boolean` makes this boundary explicit. Only `true` permits `steps: []`; `true` with steps is invalid. Missing or false retains the strict structured builder requirement for at least one valid step. Entering the interval builder removes the exemption. `simpleWorkoutModel` chooses freeform for blank/nonpositive targets, or when explicitly requested; positive simple-session targets preserve the existing untargeted Session step unless explicitly freeform. Invalid negative/fractional targets still fail validation.

Optional private `variant` is exactly `brick`, `day-off`, or `custom`, valid only with native model sport `Other`. The event remains native `WORKOUT`/`Other`; unsupported provider type names are never sent. The app can preserve these presentation categories without claiming native rest-day enforcement, mixed-leg execution, or a provider Custom sport. Generic Other and Crosstrain retain their distinct existing identities. Private variant and freeform flags survive encrypted metadata hydration, template/event descriptions and verified editor roundtrips; provider descriptions contain no model JSON.

An empty human description is sent as an actual empty string. Nonempty instructions remain inert fenced prose, so text resembling native interval syntax cannot create executable steps. Private editor/manual/planned/comment envelopes remain in the existing account-scoped encrypted sidecar, persisted before provider mutation. Independent provider GET verification allows absent/null/empty parsed definitions but rejects unexpected positive step counts, duration, distance or executable steps. Provider null descriptions are treated as empty only when the property is actually present; partial responses without a description do not authorize metadata attachment.

Duration/distance summaries preserve unknown as null, explicit zero as zero, explicit clearing as null, and omitted fields unchanged. Optional positive manual planning targets can coexist with freeform plans without manufacturing intervals. Empty freeform plans expose no profile structure or duration label; totals carry unknown flags and null computed load. Completed paired activity metrics remain independent. Paired event identity and unrelated metadata remain intact during plan editing; `athlete_cannot_edit` blocks both loading and writes.

FIT/ZWO/MRC/ERG exports reject plans without device steps before threshold requests or encoding. Text exports retain the plan title and human prose without internal metadata. Changing between freeform and structured is a verified edit of the existing event, preserving comments and manual planned values.
