# Numeric RPE workouts

The reference owner observed integer RPE targets from 1 to 10, an axis labeled 0/3/5/8/10 and blur behavior that rounds/clamps: 0 and -1 become 1; 10.5 and 11 become 10; 6.5 becomes 7. Observed independent Range defaults include Active 10min 1–8, Warm up 20min 1–5, Recovery 5min 1–7, Cool down 10min 1–5, and four Two Step Repeats containing Hard 6min 1–10 plus Easy 3min 1–7. Three Step Repeats execute three times: Hard 3min 1–9, Harder 1min 1–10 and Easy 1min 1–7. Four-stage ramps execute each blank-label 3min stage once, with upper bounds7/8/9/10 ascending or10/9/8/7 descending and lower bound1. These values come from reference inspection, not power-target conversion.

Choosing Target before adding any palette block starts every step at1. This differs from changing existing Range blocks to Target, which uses a rounded midpoint. Changing existing Target blocks back to Range uses ±5 clamped to1–10. Both observed behaviors are implemented separately, including nested repeats and ramp stages.

The UI now exposes the canonical `rpe` unit and preserves numeric effort in the desktop/mobile target editor. Incomplete typing remains local until blur; edits keep ranges ordered. The interval-builder graph uses the RPE scale for pure RPE prescriptions, and mixed imported target kinds are labeled as mixed units instead of showing RPE as a percentage. Training zones and physiological equivalents are omitted for RPE. Switching between RPE and physiological targets requires removing those existing targets first; no conversion algorithm is invented. Smooth RPE ramps are unavailable; stepped blocks retain independent integer targets.

RPE never creates a physiological TSS/IF estimate. The shared native limitation warning remains visible before save and after save. Intervals.icu receives duration/distance and human RPE step cues; the exact canonical RPE model stays in private metadata. Text export preserves the cues, while FIT/ZWO/MRC/ERG are disabled and independently rejected by the backend when they cannot retain RPE intent.
